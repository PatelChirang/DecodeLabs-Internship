# 🤖 DecodeLabs Artificial Intelligence Internship

This repository contains the projects completed during the **DecodeLabs Artificial Intelligence Internship Program**. These projects cover the fundamentals of Artificial Intelligence, Machine Learning, Recommendation Systems, and Optical Character Recognition (OCR).

---

## 📌 Project 1 - Rule-Based AI Chatbot

A simple chatbot built using Python and decision-making logic (`if-else` statements). The chatbot can interact with users, respond to predefined queries, and maintain a continuous conversation loop.

### Features

* Greeting recognition
* User interaction through console
* Exit command handling
* Continuous execution loop
* Rule-based response generation

## 🌸 Project 2 - Iris Flower Classification

A Machine Learning classification project using the famous Iris dataset. The model is trained using the K-Nearest Neighbors (KNN) algorithm to predict flower species based on flower measurements.

### Features

* Dataset loading and preprocessing
* Train-test split
* Feature scaling
* KNN classification
* Accuracy evaluation
* Prediction of flower species

### Output

![Iris Output](iris%20ss.png)

## 🎯 Project 3 - Tech Stack Recommender

A recommendation system that suggests suitable career paths and technology domains based on user skills and interests using TF-IDF Vectorization and Cosine Similarity.

### Features

* User skill input
* TF-IDF feature extraction
* Cosine similarity scoring
* Personalized recommendations
* Career path suggestions

### Output

![Tech Stack Output](tech%20stack%20ss.png)

## 📝 Project 4 - Image Text Recognition (OCR)

An Optical Character Recognition (OCR) application that extracts text from images using Tesseract OCR and OpenCV. The project demonstrates how AI can convert visual information into machine-readable text.

### Features

* Image preprocessing
* Grayscale conversion
* Text extraction using Tesseract OCR
* Printed text recognition
* Machine-readable output generation

### Output

![OCR Output](itr%20ss.png)
